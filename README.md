Fake News Detection is a Machine Learning and Natural Language Processing (NLP) project that identifies whether a given news article or news statement is Real or Fake. The system analyzes the text entered by the user and uses machine learning techniques to predict its category.
The project uses text preprocessing techniques such as removing unnecessary words, punctuation, and stopwords. The cleaned text is converted into numerical features using TF-IDF (Term Frequency–Inverse Document Frequency). Machine learning algorithms such as Naive Bayes and Logistic Regression are trained using a dataset containing real and fake news.
The application provides a simple interface where users can enter or paste news content. After analyzing the text, the system displays the prediction as REAL NEWS or FAKE NEWS. The project can also display analytics and charts to help understand the dataset and prediction results.
